***Papas con choco (de Dolores Prados)***

Ingredientes:

- Choco

- Patatas

- Cebolla

- Vino blanco

- Ajos

- Comino

- Clavo

- Pimienta negra

- Nuez moscada

- Azafrán

- Sal

- Agua

Elaboración:

- Se pene un poco de aceite para sofreír el choco a trocitos con la cebolla muy picada.

- Se le añade el vino blanco para dejar a fuego lento hasta que el choco esté tierno.

- A continuación se le añade un majado de ajo, comino, pimienta, un poco de nuez moscada, perejil y el clavo.

- A esta salsa se añaden las papas tronchadas el azafrán, el agua y la sal.

- Dejar cocer todo hasta que quede un poco trabado (cremoso) que no queden aguadas
